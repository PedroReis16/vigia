# Edge data (local mock)

Generated by `python seed-codes/seed_local_edge.py`.

Contains `identity.json`, `network.json` and `classifier.json` aligned with the
API DEBUG `TestDeviceSeed` (`Vigia-a1b2c3d4`). Point both services here:

```env
DATA_DIR=../edge-data
```

in `vigia-bootstrap/.env` and `vigia-fall/.env`, then run **Debug Edge** in VS Code.

MQTT uses host from `api_base_url` on port **81** (Traefik → Mosquitto WS).
Frame upload uses `api_base_url` as-is (default `http://localhost:8090/vigia`).
